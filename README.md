## Running the code

- **Q1:** Include `q1/posts.php` in a WordPress theme template running PHP 8+. Use `?page=2&s=term` to check pagination/search, and confirm the theme’s routing accepts `page`.
- **Q4:** Open `q4/index.html` in a browser.
- **Q5–6:** Open `q5-q6/index.html` with JavaScript enabled. The image is included locally.
- **Q9:** `q9/signup.cjs` exports a Node.js function taking a stored job and injected API/persistence functions. Queue and provider assumptions are in the answer.

The browser exercises need no installation or build step. Q1 requires WordPress; Q9 is delivery logic, not a complete newsletter service.
